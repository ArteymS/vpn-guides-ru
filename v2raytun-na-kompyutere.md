# v2RayTun на компьютере: Mac и Windows

Многие ставят v2RayTun на телефон и ищут такую же программу для компьютера. На Mac это просто: приложение есть в App Store. Официальной версии для Windows мы не нашли — но это не проблема: ваша подписка подходит к другим программам, и настройка займёт пару минут.

## Mac: v2RayTun из App Store

1. На Mac с процессором M1 и новее откройте App Store и найдите «v2RayTun».
2. Скопируйте ссылку-подписку из бота @myartvpn_bot.
3. В v2RayTun нажмите «+» и выберите добавление из буфера обмена, затем обновите подписку.
4. Выберите сервер с ответом и включите VPN; разрешите добавить VPN-конфигурацию.

> На Mac с процессором Intel версии из App Store может не быть — используйте INCY или Happ (ниже).

## Windows: та же подписка в другой программе

Скачивайте только с официальных страниц: «v2RayTun для Windows» с неизвестных сайтов может оказаться изменённой копией. Подписка из бота работает в любой из этих программ:

- **INCY** — простая, есть и на телефоне: [инструкция для компьютера](incy-na-kompyutere.md).
- **Happ** — похож на v2RayTun по устройству: [инструкция](happ-na-kompyutere.md).
- **Hiddify** — бесплатный, с открытым кодом: [инструкция](vpn-windows-11.md).
- **v2rayN** — для тех, кто любит много настроек: [инструкция](v2rayn.md).

Везде одно и то же: скопировать ссылку из бота → в программе «+» → вставить из буфера → обновить → подключить.

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Если не работает

Обновите подписку и выберите другой сервер. На Windows проверьте, что антивирус не блокирует программу, а для работы всех программ через VPN включите режим TUN. Подробнее — [«v2RayTun не работает»](v2raytun-ne-rabotaet.md).

## Частые вопросы

**Есть ли v2RayTun для Windows?**

Официальной версии для Windows мы не нашли. На Windows используйте INCY, Happ или Hiddify — подписка та же.

**Есть ли v2RayTun для Mac?**

Да, в App Store — для Mac с процессором M1 и новее.

**Можно ли одну подписку использовать на телефоне и компьютере?**

Да, если в тарифе достаточно устройств.
