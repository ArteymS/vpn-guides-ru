# Happ для Windows и Mac

Happ работает не только на телефоне: есть версии для Windows и macOS. Подписка та же, что на телефоне, — нужно лишь установить программу и добавить ссылку.

👉 **[Получить подписку — 7 дней бесплатно](https://t.me/myartvpn_bot?start=src_gh_guides)**

## Шаг 1. Установите Happ

- **Mac:** Happ есть в Mac App Store — ищите «Happ».
- **Windows:** установщик — на официальном сайте Happ и на странице проекта на GitHub. Скачивайте только оттуда: сторонние сборки могут быть изменены.

## Шаг 2. Добавьте подписку

1. В Telegram на компьютере откройте бота @myartvpn_bot и возьмите ссылку-подписку (нажмите на неё — скопируется).
2. В Happ нажмите «+» и выберите добавление из буфера обмена.
3. Обновите подписку и запустите проверку задержки — выберите сервер с ответом.

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Шаг 3. Включите

Нажмите кнопку подключения. Чтобы через VPN шли все программы, а не только браузер, включите в настройках режим TUN (может понадобиться запуск от имени администратора).

## Если не работает

Порядок действий — в статье [«Happ не работает»](happ-ne-rabotaet.md). На Windows дополнительно проверьте, что антивирус не блокирует программу.

## Частые вопросы

**Есть ли Happ для Windows?**

Да, есть версия для Windows и для macOS.

**Можно ли использовать одну подписку в Happ на телефоне и компьютере?**

Да, если в тарифе достаточно устройств.

**Чем заменить Happ на компьютере?**

Hiddify — бесплатное приложение с открытым кодом: [инструкция](vpn-windows-11.md).
