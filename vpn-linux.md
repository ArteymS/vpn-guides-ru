# VPN для Linux

На Linux VPN по подписке настраивается так же, как на Windows: бесплатное приложение плюс ссылка-подписка. Проще всего — Hiddify: у него есть готовые сборки для Linux.

👉 **[Получить подписку — 7 дней бесплатно](https://t.me/myartvpn_bot?start=src_gh_guides)**

## Шаг 1. Установите Hiddify

1. Откройте [страницу релизов Hiddify](https://github.com/hiddify/hiddify-app/releases/latest).
2. Скачайте файл для Linux: **.AppImage** (подходит почти для любого дистрибутива) или **.deb** (Ubuntu, Mint, Debian).
3. AppImage: разрешите запуск (Свойства → Права → «Разрешить выполнение») и запустите. .deb: установите двойным щелчком или командой `sudo apt install ./имя_файла.deb`.

## Шаг 2. Добавьте подписку

1. В Telegram откройте бота @myartvpn_bot и выберите «💻 Windows» — шаги те же.
2. Нажмите на ссылку-подписку — она скопируется.
3. В Hiddify: **«+ Новый профиль»** → **«Добавить из буфера обмена»**.

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Шаг 3. Включите

Нажмите кнопку включения. Чтобы через VPN шли все программы, выберите в настройках режим **VPN** (TUN) — система попросит пароль администратора.

## Если не работает

- AppImage не запускается — не выдано право на выполнение или не хватает библиотеки FUSE (`sudo apt install libfuse2`).
- Режим VPN не включается — запустите приложение с правами администратора.
- Подключено, но сайты не открываются — обновите подписку и выберите другой сервер.

## Частые вопросы

**Есть ли другие клиенты для Linux?**

Да: NekoRay и v2rayN тоже работают с подписками VLESS. Hiddify — самый простой для старта.

**Можно ли настроить без графического приложения?**

Да, через sing-box или Xray в командной строке, но это для опытных пользователей.

**Одна подписка на Linux и телефон?**

Да, если в тарифе достаточно устройств.
