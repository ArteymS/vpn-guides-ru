# v2rayN: настройка на Windows

v2rayN — бесплатная программа с открытым кодом для Windows (есть сборки для Linux и macOS). Она мощнее и сложнее, чем Hiddify: больше настроек, меньше подсказок. Ниже — короткий путь до работающего VPN.

👉 **[Получить подписку — 7 дней бесплатно](https://t.me/myartvpn_bot?start=src_gh_guides)**

## Шаг 1. Скачайте

1. Откройте [страницу релизов v2rayN на GitHub](https://github.com/2dust/v2rayN/releases/latest).
2. Скачайте архив для Windows и распакуйте в отдельную папку.
3. Запустите **v2rayN.exe**. Если Windows попросит установить .NET — согласитесь.

## Шаг 2. Добавьте подписку

1. Скопируйте ссылку-подписку из бота.
2. В меню **Подписка** откройте настройки группы подписки и добавьте новую: вставьте ссылку в поле URL.
3. В том же меню выберите **Обновить подписку** — появится список серверов.

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Шаг 3. Включите

- Выберите сервер в списке и сделайте его активным (Enter).
- Внизу окна включите **системный прокси** — заработает браузер и большинство программ.
- Чтобы через VPN шло вообще всё, включите режим **TUN** (программу нужно запустить от имени администратора).

## Проще — Hiddify

Если настройки v2rayN кажутся лишними, поставьте Hiddify: одна кнопка, тот же результат. [Инструкция для Windows](vpn-windows-11.md).

## Частые вопросы

**v2rayN и v2rayNG — одно и то же?**

Нет: v2rayN — для компьютера, [v2rayNG](v2rayng.md) — для Android.

**v2rayN подключён, но сайты не открываются**

Проверьте, что включён системный прокси или режим TUN, и обновите подписку.

**Где скачать v2rayN безопасно?**

Только со страницы проекта на GitHub.
