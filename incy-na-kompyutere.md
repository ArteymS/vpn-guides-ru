# INCY на компьютере: Windows, Mac и Linux

INCY есть не только на телефоне: разработчик выпускает версии для Windows, macOS и Linux. Подписка та же, что на телефоне, — установите программу и добавьте ссылку. Сам INCY серверов не даёт: это приложение, к которому подключается подписка VPN-сервиса.

👉 **[Получить подписку — 7 дней бесплатно](https://t.me/myartvpn_bot?start=src_gh_guides)**

## Шаг 1. Скачайте официальную версию

- **Windows и Linux:** установщики — на странице проекта на GitHub: [INCY-DEV/incy-platforms](https://github.com/INCY-DEV/incy-platforms/releases). Для обычного компьютера на Windows выбирайте файл с пометкой **x64**, для ноутбуков на ARM-процессоре — **ARM64**.
- **Mac:** на компьютерах с процессором M1 и новее можно поставить INCY из App Store; для любых Mac, включая Intel, — установщик с той же страницы GitHub.
- Не скачивайте INCY с файлообменников и «сборников программ»: такие копии могут быть изменены.

## Шаг 2. Добавьте подписку

1. Откройте бота @myartvpn_bot в Telegram на компьютере и скопируйте ссылку-подписку (нажмите на неё — скопируется).
2. В INCY нажмите «+» (добавить) и вставьте ссылку из буфера обмена.
3. Обновите подписку, чтобы появился список серверов, и выберите сервер с ответом.

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Шаг 3. Включите

Нажмите кнопку подключения. Если через VPN работает только браузер, а другие программы — нет, включите в настройках режим VPN (TUN). На Windows для этого может понадобиться запуск от имени администратора, на Mac — разрешение на добавление VPN-конфигурации.

## Если не работает

- Windows пишет, что программа неизвестна, — это обычное предупреждение для программ не из Microsoft Store: нажмите «Подробнее» → «Выполнить в любом случае», если скачивали с официальной страницы.
- Антивирус блокирует подключение — добавьте INCY в исключения.
- Серверы не отвечают — обновите подписку и выберите другой сервер.

Остальные шаги — в статье [«INCY не работает»](incy-ne-rabotaet.md).

## Частые вопросы

**Есть ли INCY для Windows?**

Да. Официальные установщики для Windows, macOS и Linux — на странице проекта INCY-DEV/incy-platforms на GitHub.

**Можно ли одну подписку использовать на телефоне и компьютере?**

Да, если в тарифе достаточно устройств: ссылка одна и та же.

**INCY на компьютере бесплатный?**

Само приложение бесплатное. Для подключения нужна подписка VPN-сервиса — у нас первые 7 дней бесплатно.

**Чем заменить INCY на компьютере?**

Happ или Hiddify — подписка подходит к любому из них: [Happ](happ-na-kompyutere.md), [Hiddify](vpn-windows-11.md).
