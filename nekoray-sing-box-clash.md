# NekoRay, sing-box, Clash Verge: что это и чем пользоваться

Эти три названия часто встречаются в инструкциях для компьютера. Все они — программы или «движки» для VPN-подключений, но устроены по-разному и понимают разные форматы подписок.

## sing-box

Это «движок» — ядро, на котором построены многие приложения, например Hiddify и Karing. У sing-box есть и собственные приложения, но им нужен готовый файл настроек в своём формате: обычная ссылка-подписка им не подходит. Если хочется sing-box без ручной настройки — берите Hiddify или Karing.

## NekoRay (NekoBox для компьютера)

Программа для Windows и Linux на ядре sing-box, понимает подписки VLESS. Автор прекратил её развитие, поэтому новые версии выходят у сторонних продолжателей. Для новой установки надёжнее Hiddify или v2rayN; версия для телефона — [NekoBox](nekobox.md).

## Clash Verge

Программа на ядре Clash (mihomo). Она работает с подписками в формате Clash — это другой формат, чем обычная подписка VLESS. Если сервис не выдаёт отдельную ссылку «для Clash», подписка в неё не добавится.

## Частые вопросы

**sing-box — это VPN?**

Это ядро для VPN-приложений. Сам по себе доступа не даёт — нужен сервер и настройки.

**Подойдёт ли подписка VLESS для Clash Verge?**

Только если сервис выдаёт ссылку в формате Clash. Обычная подписка VLESS не подойдёт.

**NekoRay ещё работает?**

Да, но развитие исходного проекта остановлено. Для новой установки лучше Hiddify или v2rayN.
