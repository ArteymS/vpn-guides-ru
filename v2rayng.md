# v2rayNG: как добавить подписку на Android

**v2rayNG** — бесплатное приложение для подключения к VPN. Само по себе оно ничего не открывает: в него нужно добавить **подписку** — ссылку от VPN-сервиса, в которой лежат серверы. Ниже — как установить v2rayNG на Android и добавить подписку за пару минут.

👉 **[Получить подписку — 7 дней бесплатно](https://t.me/myartvpn_bot?start=src_gh_guides)**

## Шаг 1. Установите v2rayNG

v2rayNG есть в **Google Play**; разработчик также выкладывает установочные файлы на GitHub (2dust/v2rayNG). Это приложение только для Android.

## Шаг 2. Получите подписку

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Шаг 3. Добавьте подписку одним касанием

Для Android удобнее Hiddify или INCY — их бот подключает в одно касание. Если вы уже пользуетесь v2rayNG, добавьте подписку вручную по шагам ниже — она работает так же.

## Если удобнее вручную

1. Скопируйте ссылку-подписку из бота.
2. В v2rayNG откройте меню (три полоски) → **«Группы подписок»** (Subscription group setting).
3. Нажмите **«+»**, вставьте ссылку в поле URL, задайте любое название и сохраните.
4. Вернитесь на главный экран, откройте меню (три точки) → **«Обновить подписку»**.
5. Выберите сервер и нажмите круглую кнопку внизу.

## Шаг 4. Включите VPN

Выберите в списке сервер и нажмите кнопку включения. При первом запуске телефон спросит разрешение на VPN-подключение — разрешите. В подписке MyArtVPN три сервера: **🚀 Основной**, **🛡 Запасной** и **🇷🇺 Россия**. Если один работает плохо в вашей сети, переключитесь на другой.

> Проверить, что всё работает, можно в боте: кнопка «📡 Проверить подключение» покажет, видит ли сервер ваше подключение.

## Частые вопросы

**Почему в v2rayNG не видно серверов после добавления подписки?**

Подписку нужно обновить: меню → «Обновить подписку». Без этого v2rayNG не загружает серверы.

**Можно ли добавить ключ без подписки?**

Можно через «+» → импорт из буфера, но подписка удобнее: серверы обновляются автоматически.
