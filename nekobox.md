# NekoBox: как добавить подписку

**NekoBox** — бесплатное приложение для подключения к VPN. Само по себе оно ничего не открывает: в него нужно добавить **подписку** — ссылку от VPN-сервиса, в которой лежат серверы. Ниже — как установить NekoBox на Android и компьютер и добавить подписку за пару минут.

👉 **[Получить подписку — 7 дней бесплатно](https://t.me/myartvpn_bot?start=src_gh_guides)**

## Шаг 1. Установите NekoBox

NekoBox для Android и NekoRay/NekoBox для компьютера распространяются через GitHub. Скачивайте только со страницы разработчика.

## Шаг 2. Получите подписку

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Шаг 3. Добавьте подписку одним касанием

Для Android проще Hiddify или INCY — их бот подключает одним касанием. NekoBox настраивается вручную по шагам ниже.

## Если удобнее вручную

1. Скопируйте ссылку-подписку из бота.
2. Откройте NekoBox → раздел **«Группы»** (Groups) → **«+»**.
3. Тип группы — **«Подписка»**, вставьте ссылку в поле URL и сохраните.
4. Обновите группу и выберите сервер.

## Шаг 4. Включите VPN

Выберите в списке сервер и нажмите кнопку включения. При первом запуске телефон спросит разрешение на VPN-подключение — разрешите. В подписке MyArtVPN три сервера: **🚀 Основной**, **🛡 Запасной** и **🇷🇺 Россия**. Если один работает плохо в вашей сети, переключитесь на другой.

> Проверить, что всё работает, можно в боте: кнопка «📡 Проверить подключение» покажет, видит ли сервер ваше подключение.

## Частые вопросы

**NekoBox не видит серверы**

Обновите группу подписки. Проверьте, что ссылка вставлена целиком.

**Безопасно ли скачивать NekoBox?**

Скачивайте только со страницы разработчика на GitHub — сборки с посторонних сайтов могут быть изменены.
