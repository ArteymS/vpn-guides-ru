# VPN для Windows 11 и 10

На Windows встроенный VPN рассчитан на старые протоколы, поэтому для современных подписок нужен отдельный бесплатный клиент. Проще всего — Hiddify: он работает на Windows 11 и 10.

👉 **[Получить подписку — 7 дней бесплатно](https://t.me/myartvpn_bot?start=src_gh_guides)**

## Шаг 1. Установите Hiddify

1. Откройте [страницу релизов Hiddify](https://github.com/hiddify/hiddify-app/releases/latest).
2. Скачайте файл **Hiddify-Windows-Setup-x64.exe** и запустите установку.
3. Если Windows покажет предупреждение SmartScreen — нажмите «Подробнее» → «Выполнить в любом случае»: это обычное поведение для программ с открытым кодом.

## Шаг 2. Добавьте подписку

1. Откройте бота @myartvpn_bot в Telegram на компьютере и выберите «💻 Windows».
2. Нажмите на ссылку-подписку — она скопируется целиком.
3. В Hiddify нажмите **«+ Новый профиль»** → **«Добавить из буфера обмена»**.

> **Где взять подписку.** Откройте бота **@myartvpn_bot** в Telegram и выберите устройство — пробный период на 7 дней бесплатно, без привязки карты включится сам. Бот покажет вашу личную ссылку-подписку и кнопку «Подключить в одно касание»: приложение откроется и добавит профиль без копирования.


## Шаг 3. Включите VPN

Нажмите большую кнопку включения. Для работы всех программ, а не только браузера, в настройках Hiddify выберите режим **VPN** (TUN); Windows может попросить права администратора.

## Если не работает

- Антивирус или брандмауэр блокирует Hiddify — добавьте его в исключения.
- Включён другой VPN-клиент — выключите его.
- Неверное время в Windows — включите «Установить время автоматически».
- Подписка устарела — обновите её в Hiddify и выберите другой сервер.

Расшифровка частых ошибок — в статье [«Ошибки VPN»](oshibki-vpn.md).

## Частые вопросы

**Можно ли настроить VPN в Windows без программ?**

Встроенный VPN Windows не поддерживает протокол VLESS, поэтому нужен клиент — например, бесплатный Hiddify.

**Работает ли Hiddify на Windows 10?**

Да, на Windows 10 и 11 (64-бит).

**Есть ли бесплатный VPN для Windows 11?**

Сами приложения бесплатны, а серверы предоставляет сервис. В MyArtVPN первые 7 дней бесплатно, без привязки карты ([о бесплатных VPN](besplatnyj-vpn.md)).
